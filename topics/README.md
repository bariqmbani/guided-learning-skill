Your current tokenization course stays in its original folders, preserving its notes and links. New subjects get separate folders under `topics/`.

## Start or continue

- **Continue tokenization** resumes your existing course.
- **I want to learn Japanese** creates an independent track.
- **Continue my roadmap** resumes the last selected topic.
- **Add this concept to my tokenization roadmap** explicitly extends that course.

Restart an existing agent session after this update, or ask it to reread the guided-learning skill and its topic-routing instructions before continuing.
