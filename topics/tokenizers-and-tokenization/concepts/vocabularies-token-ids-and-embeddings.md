# Vocabularies, Token IDs, and Embeddings

## Core claim
A tokenizer's vocabulary maps each recognized token string to an integer ID, and a language model uses that ID to select a learned vector from its embedding table. The mapping is part of the model's interface: changing token-to-ID assignments changes what the model reads and writes.
