# bariqmbani learning vault

@/home/bariqmbani/.codex/RTK.md

Treat this directory as the vault root. All learning paths are relative to it.

For learning, studying, quizzes, papers, topic bootstrapping, or continuing a roadmap, read and follow `SKILLS/guided-learning/SKILL.md`. The project skill is registered through `.agents/skills/guided-learning` and `.claude/skills/guided-learning`.

The initial roadmap has no concepts. Treat a roadmap with no concept checklist entries as empty and use the skill's Bootstrapper when the learner names a topic. Ask for their learning goal at the first session as the skill specifies. Do not invent a topic or mark progress before a real learning session.

Keep concept notes in `concepts/`, paper summaries in `literature/papers/`, the roadmap and recall queue in `learning/`, journals in `learning/protocols/`, the glossary in `research/glossary.md`, and execution logs in `SKILLS/guided-learning/logs/`.

Use Obsidian wikilinks for notes. Preserve the learner's existing notes and track progress, recall, and comprehension from actual sessions. After creating or editing interactive HTML, run `learning/interactives/build.sh` from the vault root to inline the shared stylesheet.
