Three things to try

1. Compare 30 and 80. Keep the sample population fixed. Explain which review queue you would choose if missing a real case were costly.

2. Push to 100. Nothing is flagged. Why is precision undefined while recall is zero?

3. Explain the denominator. Which samples count in precision? Which count in recall?

Model assumptions and exact scores

This is an invented score dataset, not a trained classifier or a calibrated probability model. All scores are below 100. Higher thresholds can only reduce the flagged set; precision can fluctuate in a finite dataset. A balanced population does not represent every real use case.
