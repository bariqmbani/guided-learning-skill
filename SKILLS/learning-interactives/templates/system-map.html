04 · Explain it

Select Compile. Name every stage that cannot start if compilation fails, and name one stage that is unaffected. What does the unaffected stage tell you about where you could parallelise work?

Reveal a worked check

Compile blocks unit tests, packaging, and deployment, because each waits on the stage before it. Linting is unaffected: it reads the source directly, so it can run at the same time as compilation rather than after it.

Transfer the idea

Draw the same two columns for a task you own: what each step waits for, and what waits on it. Which step would you make faster first, and does that step actually sit on the longest chain?

Model limits. This is a fixed, acyclic example of a small build pipeline, not a measurement of a real project. Arrows mean "must finish before", which is a scheduling constraint, not a claim about cause. Real pipelines add caching, retries, parallel branches, and failures that are not the fault of the stage that reports them.
Read every arrow twice: once forward, once backward.
