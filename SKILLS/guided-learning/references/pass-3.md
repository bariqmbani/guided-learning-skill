# Pass 3 — Fluency

Read only for the current Fluency pass. The goal is to use the concept in writing
or argumentation without prompting, in the learner's domain.

## Explain and practise

Use the relevant original material and a demanding application:

- Read key source sections together and critique methodological choices.
- Have the learner deploy the concept in a paragraph: a research argument,
  recommendation, or practical explanation. Stress-test it with an objection.
- Combine it with two or three other concepts into a coherent argument chain.
- Identify the strongest counter-evidence and limitations honestly.
- Ask for an explanation to a newcomer who needs to use or implement the idea.

Use appropriate writing and discussion rather than assuming academic work in
professional or self-study mode. Follow shared teaching for support and a fresh
independent attempt.

## Check comprehension

Choose one format below for the current domain; do not repeat the previous
session's `check_format`. Retain its ID in the execution log and adapt wording
to the actual concept and language while retaining the underlying task. Let the
learner explore a relevant interactive first, then ask and wait. Address gaps
before advancing.

| Shared ID | Prompt |
| --- | --- |
| `counter-argument` | Name a paper or concept that could argue against this claim. |
| `teach-it` | Explain to a newcomer. Research: a student who has not read the paper and needs to implement it; professional: a team member starting Monday; self-study: a motivated beginner seeking understanding rather than memorization. |

| Task | Research | Professional | Self-study |
| --- | --- | --- | --- |
| Write for an audience | `related-work`: Write one Related Work sentence about this. | `decision-memo`: Write the recommendation paragraph for a decision document. | `blog-post-opener`: Write a blog's opening paragraph explaining this. |
| Defend the concept | `reviewer-sim`: Reviewer 2 calls your use superficial. Defend it. | `pushback-sim`: A skeptical colleague calls this over-engineered. Defend it. | `skeptic-response`: Someone on Twitter calls it overrated. Draft a reply. |
| Connect to your work | `hypothesis-link`: Which hypothesis does this support, and how would you cite it as evidence? | `project-link`: Which current project benefits most, and how? | `portfolio-link`: How would you demonstrate understanding in a portfolio project? |
| State a caveat | `write-limitation`: Write a two-sentence limitation paragraph for your system. | `write-risk`: Write a two-sentence risk assessment for not applying it. | `write-caveat`: Write the two-sentence “here's the catch” paragraph. |

## Connections

Ask where this belongs in an argument or knowledge map:

- **Research:** what does it support in the dissertation argument, and what
  supports it?
- **Professional:** which team decisions does it inform, and which prerequisites
  does it need?
- **Self-study:** where does it sit in the concept map, what supports it, and
  what does it enable?

Invite at least two upstream and one downstream connection, with reasoning.
