What the algorithm does
  1. Set low and high to the ends.
  2. Compare the middle value.
  3. If too small, move low right.
  4. If too large, move high left.
  5. If equal, return the index.

Model limits. This trace uses a fixed, sorted array of distinct numbers and an existing target. Binary search requires sorted data. For duplicate values, this version can find a match without guaranteeing the first match. Seven visual steps represent three comparisons, not seven comparisons.
