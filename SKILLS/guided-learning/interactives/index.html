Choose the question your learner needs to answer. Start with a working experiment, then adapt its model, evidence, and prompts. Ten patterns, one component set, no dependencies.

For tutors and authors

Choose a template, scaffold a new file in an installed learning workspace, and adapt the sections marked EDIT. Check the model and learner experience before sharing.

python3 scaffold.py parameter-explorer /path/to/vault/interactives/YYYY-MM-DD_concept.html

Run from this toolkit directory using the workspace’s configured Python interpreter. The new HTML embeds its CSS and JavaScript. Existing files and customized assets are protected.
