# Unigram Language-Model Tokenization

## Core claim
Unigram tokenization starts with a large candidate vocabulary and assigns scores to pieces, then removes pieces that contribute least to the model's ability to explain the training text. A string can admit multiple segmentations, and the method can choose among them using the learned piece scores.
